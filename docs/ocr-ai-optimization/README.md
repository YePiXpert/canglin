## 原件事实

13 份都是致远（Seeyon）OA 打印页导出的 A4 PDF，单页或两页，带完整文本层，没有扫描图，表格边框是矢量曲线（pdfplumber 的 `curves`）。分两种模板：

| | 办公用品领用单（8 份） | 固定资产购买申请单（5 份） |
| --- | --- | --- |
| 标题 | 办公用品领用单 | 固定资产购买申请单 |
| 单号 | 流水号，10 位数字，表格上方独立一行 | 编号，9 位数字，与"单位：元"同一行 |
| 单据头 | 申领部门、经办人、申领日期在表格上方同一带边框的行 | 申请单位部门（出现两次，第二次为空）、申请日期、使用范围、资金来源在顶部；经办人和日期在页面底部 |
| 明细列 | 序号、物品名称、数量、单价、备注 | 序号、资产名称、类别、规格型号（两行表头）、生产厂家（两行表头）、主要技术指标、数量、预计单价、预计总价 |
| 单价 | 全部为空；"总金额 0.00 元"固定出现 | 预计单价、预计总价有值，乘积相符 |
| 备注列 | 采购链接（cemall、京东，京东链接带跟踪参数拆成 9 行），或"50张""一个""5盒""三种型号各两个"这类单位与说明 | 无 |
| 规格 | 嵌在品名里："A4打印纸(规格：80g)--（5包/箱）""装订胶圈（蓝色、8mm)""(单位：包)" | 独立列；型号在格内按字符换行（"SF-CH-23" 换行 "06A黑框"） |
| 表格后 | 插入项、总金额、部门领导意见、办公用品管理员意见、归属月份 | 插入项、合计、七级审批意见（【同意】加"[姓名 日期 时间]"）、附件、经办人与日期 |

共同特点：数量以"10.0"形式出现；单元格内按字符换行，型号、链接和部门名都会被拆行（"综合管理部（董事" 换行 "会办公室）"）；浏览器打印页眉页脚（"print""Page 1 of 2"、print.jsp 链接、打印日期"2026/8/31"）混在文本层里；续页没有表头，列位置与首页完全一致；明细行的输入框边线与单元格边线相距几个 pt；表头行自己的分隔线位置与数据列不同，固定资产单的表头没有竖线；表单的"标签 | 值"分隔线在 x 上与表格列线重合但在表格区域内没有线段。

## 总体设计

```
原件页
 ├─ PDF 且有文本层 ──► 网格重建（01）──► 有明细行 ──► AI 审核模式（02，可选）──► 草稿
 │                                   └─ 无明细行 ──► 按图像页处理
 ├─ 截图 / 照片 / 无文本层 PDF ──► AI 识别模式（02）──► 失败页 ──► 本地 OCR（03）──► 草稿
 └─ 两者均失败 ──► 人工补录并逐页核对（现有流程不变）
```

原则：

1. 文本层是无损数据，文字、数字、链接以文本层为准；图像只用来确认版式。网格重建不需要 AI，也不需要加载 Paddle 模型。
2. AI 在文本层页面只做核对、品名与规格拆分、单位判断和疑点标注；在图像页面才做主识别。模型改不了确定性结果里的数字和链接，只能写警告。
3. 不猜值：数量、单价、单位不确定就留空并警告。总金额 0.00 不是单价，总价除以数量不是单价。
4. 保留物理行：同名、同规格的行分别保留，不合并不排序；每行保留原文 `rawText` 让拆分可追溯。
5. 识别输出带来源：文本层行带页内坐标，AI 行只带页码，不伪造坐标。
6. 每次改动可评测、可回退：提示词有版本号，调用记录带版本，网格重建有开关。

## 验收口径

- 样本：13 份原件、30 条物理行、52 个单据头字段（每份流水号或编号、部门、经办人、日期）。
- 网格重建：30/30 行，0 假行，品名原文逐字相同，数量、链接、规格列、备注解释正确；52/52 单据头字段，换行的部门名拼接完整；单页解析在 1 秒内。
- AI 审核模式（需真实服务）：数量、链接与网格结果一致率 100%（由服务端校验保证）；品名与规格拆分经人工认可不低于 90%。
- AI 识别模式（截图与照片）：按 05 的评测门槛，不低于当前版本。
- 回归：`pnpm test`、`(cd apps/ocr && pytest)`、浏览器测试、部署脚本测试与评测脚本测试全部通过；类型检查、lint、构建通过。
