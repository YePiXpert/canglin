| 真实增量迁移 | 从 Beta 1 迁移链建立隔离库后升级；原采购金额/付款标记/附件编号、外键和原 CHECK 保留，新金额/状态/归属约束与有效票号唯一性生效 |

规模耗时是本机测量，不作为目标部署机器的性能承诺。资金边界回归包括不同员工不抵销、合并付款逐单撤销限制、期初纠错、历史垫付已退清但员工仍欠报销款、跨月冲回、发票冲减、异常到期与恢复。AI 回归包括超时、非法输出、范围外 ID、超额金额、生成期间变化、失败/重启重试和成功不重复调用。

本机浏览器使用 `/usr/bin/chromium`：

```bash
pnpm build
pnpm typecheck
pnpm lint
pnpm test
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium pnpm --filter @canglin/web test:e2e
apps/web/scripts/visual.sh
```

未改动的 Python OCR/部署脚本没有将 Beta 1 的验收数字算成本轮新结果。本轮没有调用真实付费模型来评估发票识别率，也没有接入物理手机摄像头或打印机；这些保留为现场试用项目。二维码照片读取及相机不可用回退已由浏览器实际执行。
